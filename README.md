# SKY — primera versión web

Interfaz web responsive inspirada en las referencias: azul y violeta, superficies claras, una mascota expresiva y una navegación sencilla.

## Abrir

Abre `index.html` en un navegador. No requiere instalación ni compilación.

## Incluye

- Bienvenida para nuevas visitas con preguntas opcionales de contexto; el perfil se guarda en el navegador y se puede editar después.
- Inicio con registro de ánimo, resumen diario, accesos rápidos, objetivos activos, semana visual, racha y mensajes amables de SKY.
- Un acceso flotante a SKY disponible en todas las pantallas para abrir el chat, guardar un momento o revisar objetivos.
- Timeline con calendario, check-in de ánimo y registros diarios de actividad y estado emocional.
- Objetivos activos y completados con emoji, progreso editable y sugerencias que solo se añaden si la persona las elige.
- Insights sobre descanso, motivación y momentos difíciles, calculados a partir de registros reales y con un mínimo de tres días distintos.
- Pausa guiada de respiración de un minuto, con opción de terminarla en cualquier momento.
- Cuatro expresiones de SKY: curioso, feliz, pensativo y apoyando.
- Diseño adaptable a ordenador y móvil.

## Límites de esta versión

Los datos viven en el navegador actual; todavía no hay cuentas ni sincronización entre dispositivos. El chat de IA y el backend aún no están conectados. Los insights esperan suficientes registros y no muestran estadísticas inventadas.
